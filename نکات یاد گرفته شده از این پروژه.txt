تابع sort (  ) اگه همینطوری استفاده بشه با اجزای داخل حالا یا آرایه یا آبجکت ها مثل یه رشته رفتار میکنه حتی اگه عدد باشه.
بخاطر همین وقتی میخایم عدد هارو به ترتیب بچینیم فک میکنیم مشکلی پیش اومده اما اینطور نیست و تابع sort اون هارو مثل رشته میبینه و بصورت کاراکتر باهاشون رفتار میکنه. بنابراین میاد میبینه اولین رقم چه عددیه و بر اساس اولین رقم ها ترتیب بندی میکنه 
مثال: 
const points = [40, 100, 1, 5, 25, 10];
points.sort (  ) ;
که poinst تبدیل میشه به:
[ 1, 10, 100, 25, 40, 5 ];

برای اینکه درست عمل کنه باید با  compare function عمل sort رو انجام بدیم:
points.sort ( function ( a, b ) { return a - b } ) ;
